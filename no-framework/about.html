About This Site

This small site is a template demonstrating a minimal structure suitable for small projects, portfolios, or learning exercises. It uses plain HTML, a single stylesheet, and a single JavaScript file to keep things simple.

Design Goals

  • Small footprint (only five files)
  • Clear structure and accessible markup
  • Responsive layout with simple components

How to customize

Edit styles.css for visual changes, modify the HTML files for content and structure, and extend behavior in script.js.
